# MOVE ON — клікабельний прототип

Мобільний прототип (PWA) навчального проєкту MOVE ON з дисципліни «Дизайн-мислення та розвиток креативності», КНЕУ, 2026.
Команда: Анна Білостоцька, Євгеній Іванов, Денис Михалюк.

Що перевіряє прототип: перший крок до особистої цілі за хвилину без реєстрації, «дерево цілі», що росте й в'яне, пропозицію малого депозиту після трьох днів і повернення після пропуску.

Імітовано: платежі, акаунти, інтеграції, віджет і нагадування. Гроші не списуються.

Панель модератора: довге натискання на лого «MOVE ON» або потрійний тап по номеру версії.
